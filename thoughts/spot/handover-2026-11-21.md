## Traps discovered (do not repeat)

1. **Bare `MUI_NewObject("UP-Cycle.mcc", TAG_DONE)` hard-freezes the
   machine** (no Guru, dead daemon). Real UP-MCC bug — report to spot.
   Never create Cycle without `UPA_Cycle_Entries`.
2. **Wedge-reboots corrupt DH0:.** Files `list` fine but read as Error 205
   ("Unknown command" on run). Always `get`+md5 the binary after upload
   and after any wedge before theorizing. `rig.py stop` wipes `build/rig2`
   (re-clone); `reboot` preserves DH0:.
3. **`wasabi run` (foreground) never returns for GUI apps that stay open**
   and blocks the single-threaded daemon. Prefer `Run >NIL: <NIL:` +
   `uitree`, or `ami.py exec "cmd" <secs>`.
4. Rig 2's wasabi **debug stream is held by another session** (PID 79090,
   8 days old — do not kill). Its log file is readable, but our
   RawPutChar markers never showed up there.
5. `screencapture` catches the wrong display; FS-UAE window ID lookup
   needs Quartz (absent). `ami.py shot` works headless instead.
6. UP-Demo AUTO is the 10-second environment proof. `tclasses`, `tstack`,
   `probe_groups`, `skiprun`, `linktest` sources live in
   `ReleasePacker/scratch-rig/`; binaries in `/tmp` (gone on reboot —
   rebuild as needed).
