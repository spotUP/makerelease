    Revoke a release
    
    
    Removes the catalog entry, frees the release number and the code, deletes the published archive, and moves the WordPress post to the trash (recoverable in wp-admin for 30 days). Works on any release, including one from an earlier session — but only on the most recently created one, so revoke newest first.
