Up Rough Release Maker - macOS
==============================

1. REQUIRED TOOLS

   The app shells out to "lha" and "zip" to pack archives.
   macOS ships "zip" already. Install "lha" with Homebrew:

       brew install lha

   Without it, LHA builds fail with a message telling you the same thing.

2. INSTALL

   Unzip and drag makerelease.app to Applications. One app runs natively
   on both Apple Silicon and Intel Macs.

3. FIRST LAUNCH

   The build is not signed with an Apple Developer ID, so Gatekeeper will
   refuse it the normal way. Right-click the app and choose Open, then
   confirm. On newer macOS versions use System Settings > Privacy &
   Security > "Open Anyway" instead.

   If macOS still blocks it, clear the quarantine flag:

       xattr -cr /Applications/makerelease.app

4. WHERE YOUR BUILDS GO

       ~/Documents/Up Rough Releases/

   The app prints the full path after every build.
