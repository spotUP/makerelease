Up Rough Release Maker - macOS
==============================

1. REQUIRED TOOLS

   The app shells out to "lha" and "zip" to pack archives.
   macOS ships "zip" already. Install "lha" with Homebrew:

       brew install lha

   Without it, LHA builds fail with a message telling you the same thing.

2. INSTALL

   Open the .dmg for your Mac and drag the app to Applications.

       Up Rough Release Maker-0.1.0-arm64.dmg   Apple Silicon (M1/M2/M3/M4)
       Up Rough Release Maker-0.1.0.dmg         Intel

3. FIRST LAUNCH

   The build is not code-signed, so Gatekeeper will refuse it the normal
   way. Right-click the app and choose Open, then confirm.

   If macOS still blocks it, clear the quarantine flag:

       xattr -cr "/Applications/Up Rough Release Maker.app"

4. WHERE YOUR BUILDS GO

       ~/Documents/Up Rough Releases/

   The app prints the full path after every build.
