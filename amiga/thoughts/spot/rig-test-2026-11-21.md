## Bugs found and fixed (uncommitted, in src/)

1. **The freeze: `SetAttrs`/`GetAttr` called through a NULL IntuitionBase.** `src/ui_amiga.c`
   does `#define IntuitionBase shell_IntuitionBase` and only set it inside `shell_requester()`
   (it set it back to NULL afterwards). The inline `SetAttrs(win, MUIA_Window_Open, TRUE)` in
   `shell_main()` (the first intuition call after building the window) jumped through a NULL
   library base, so the machine wedged with no Guru. Fix: `rp_ui_run()` opens intuition.library 36
   for the whole run and closes it at the end. `shell_requester()` restores the previous base
   instead of NULL. After the fix the window opened on the first try.
   (Static diagnosis from the source plus the fix working; the old binary was not re-run under a
   breadcrumb bisect.)
2. **Build failed "archiver failed (return code 20)".** The command was
   `lha a "PROGDIR:releases/DM-RT1.LHA" ...`. `PROGDIR:` is per process, so lha (started by
   `SystemTagList`) resolves it to its own drawer: `LhA: Could not create archive
   'PROGDIR:releases/DM-RT1.LHA'`. Fix in `shell_build()`: resolve `PROGDIR:releases` with
   `Lock`+`NameFromLock`+`AddPart` and pass the absolute path to the archiver.
3. **lha without `-r` flattens `BASE/`** (the NFO landed at the archive root). `src/archive.c` now
   emits `"lha" -r a ...`; `tests/test_stage.c` expectation updated to match.
